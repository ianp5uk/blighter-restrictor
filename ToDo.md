## Features
* Would be good to not need to use static addresses and fixed MAC. Setting this would confuse and worry a non-technical user
* Should collect activity even if filtering paused - this is on the plan.
* Rules should always be shown in parent app, if not connected should show last known but perhaps in dark grey or blue font
* A new "Controls" tab with:
  * Add override buttons; block everything button + an open everything button - should not lose filters, so could be a 3 way radio button set;
    Normal opertion, Block everything, Open everything.
  * Provide a remote log out & a shutdown PC immediately
  * A scheduled shutdown or logout function, with option for warning message. Should be capable of absolute
    or difference time, i.e., 21:00 or +2:15 (2 hours & 15 mins) by parent device clock.
* On the laptop panel the Pause or Resume filtering can move to this new Controls tab as first items.
